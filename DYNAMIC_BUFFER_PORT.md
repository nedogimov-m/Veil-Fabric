# Native dynamic buffer boundary

The native attachment, shader, cache, automatic ordinary-pass capture and automatic native OIT accumulation/composition pass affected checks on actual Minecraft 26.3 Vulkan. A real LevelRenderer world GameTest also passes three submitted property frames. Classic source-alpha generic-property blending now passes affected automatic checks. The native first-person and independent world-perspective helpers have their own affected proofs; complete facade/post/global startup remains separate. No complete Veil runtime/JAR is available.

`NativeDynamicBufferTarget` owns typed dynamic attachments. A retained snapshot captures the actual mask, dimensions and generation. Resizing/reconfiguring the owner allocates replacements first; old snapshots retain their own views through submission and owner disposal. `extend(RenderPassDescriptor)` preserves the caller's exact original color/depth attachments, clear/load values, render area and label, then appends the selected native attachments. It never owns caller views. `pipeline(original)` preserves the real immutable shader/define/binding/vertex/topology/depth/cull/push-constant state and appends actual color states.

`DynamicBufferProcessor` now understands native named vertex elements, `sample_lightmap`, real uniform-block members and explicit matching varying locations. Native BLOCK no longer supplies normals, so those surface normals come from derivatives of an interpolated view-space position. Sources with actual normal attributes retain transformed native normals. Albedo retains the actual ColorModulator from its typed block. Markers remain the real GLSL parser's annotations; debug marker values are checked in a native RGBA16F attachment.

`NativePipelineBridge.compileVariant` detaches original native source/includes before scheduling asynchronous work and returns a genuine native Pending. The original native cache retains its original compiled owner. The caller finishes the Pending on the render thread and owns the derived actual compiled pipeline; original extension binding metadata follows that owner. Source/define/vertex contracts remain explicit. No wrapped substitute compiled pipeline is installed in Minecraft.

`VanillaShaderCompiler` now caches these real mask/state variants. `prepare` schedules actual compiler work; `retain` finishes/leases one exact compiled owner. Equivalent immutable native states share a pending result. Cache clear, native base retirement and compiler close retire their ownership while selected leases remain valid through submission. An unconsumed Pending is still finished/disposed on the supplied render executor when workers complete. `retirement()` reports completion of the currently retired owners. Render shutdown must allow that executor to process disposal while the native device is alive.

The new `dynamic`, `dynamicvariants` and `dynamiccache` selections cover these distinct affected contracts. Historical passing unrelated GPU selections are not rerun:

`DynamicBufferManager` now owns genuine typed world outputs and combines independent source requests transactionally. `NativeDynamicBuffers` and the production native encoder/pass/LevelRenderer mixins append descriptors before opening passes, select real compiled variants, and retain both storage and pipeline owners through actual encoder submission. Pass close does not release queued owners. Minecraft uses one shared native encoder; scope entry records clears without submitting it. Clear-only selections are retained too. Nested worlds receive independent same-size storage, and explicit post contexts suspend output capture while retaining their selected world input views. `VeilRenderer` supplies the actual native post-manager constructor and drains pending compiler retirement while the device is live.

`DynamicBufferProcessor.producedBuffers()` records actual emitted fragment outputs. The compiler disables writes to unproduced attachment states, preserving prior property pixels. Direct Veil native pipelines retain source text before their resource sources close, allowing actual derived variants. Managed ShaderManager replay retains immutable raw roots and a fresh processor recipe so branches removed from the mask-zero base are recovered for each selected mask. The replay keeps the actual ProgramDefinition and exposes both Veil and Minecraft processor contexts. Original native pipeline flags and arbitrary string define values survive managed compilation. The real originals of the replaced GL manager/shard/accessor/world mixins are retained under `upstream-retired/dynamicbuffer`, with a feature map in its README.

New `dynamicworld` acceptance passes actual vanilla and source-retired direct managed draws through unmodified caller descriptors and genuine production frontend interception. Native pixel readback covers all four debug components and preserved unproduced outputs. It also verifies independent requests, physical offscreen target isolation, nested same-size worlds, post capture suspension, and storage/pipeline retirement across request changes/resize/owner close until actual submission. Evidence: `gpu-dynamic-world-runtime.log`, `build/gpu-verification/dynamicworld-{runtime,inputs}.json`.

OIT uses separate floating-point property payloads and packed per-property produced-coverage weights, then resolves all four property components from copied opaque snapshots using actual native wavelet coverage and vanilla accumulator normalization. All five properties fit the eight native attachments using two packed weight targets. Generic property W stays payload, including negative and greater-than-one debug values. Additive stages contribute weighted payload with zero produced coverage; unsupported channels preserve opaque values. Actual provider phases select accumulation only, preserving depth-bounds/transmittance stages. Ordinary UNORM/SNORM attachments are never appended to the native OIT accumulator.

`NativeDynamicCoverage` and its post-dynamic AST processor now separate ordinary geometry alpha from all four property payload components. Five floating-point XYZ/coverage targets plus two packed RGB W targets fit eight total attachments including native color. Native color blend equations apply to XYZ and packed W using the actual fragment's final geometry alpha. The initializer captures real typed property values and native main alpha (or descriptor clear alpha) before opening each pass; the resolver restores typed final property views immediately after the native pass closes. This preserves externally updated post/OIT inputs and avoids texture feedback. Static produced masks protect missing properties and individual packed RGB neighbors, while geometry-alpha storage remains synchronized. Generation/frame leases own genuine storage, samplers, initializers and resolvers through submission.
